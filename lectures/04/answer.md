### 調査したベンチマーク

- **データセット名**：GPQA Diamond

GPQA は、生物学・物理学・化学の専門知識を問う四択問題のベンチマークである。このうち GPQA Diamond は、専門家による検証などの条件を満たした 198 問からなる。

### 読んだ問題の要約

#### 問1：物理（一般／天文）年周視差ごとの星の数

| 項目 | 内容 |
|---|---|
| 何を問うか | 星が空間に一様に分布していると仮定する。そのとき、年周視差 plx の単位幅あたりの星の数が plx にどう依存するかを、plx の −1 乗から −4 乗までの4択から選ぶ |
| 正解の考え方 | 距離が r から r+dr の殻に入る星の数は r²dr に比例する。r = 1/plx と置き換えると dr の大きさは dplx/plx² になるので、星の数は (1/plx²)·(1/plx²) = plx⁻⁴ に比例する |
| 誤答の作り | 変数変換の係数（ヤコビアン）を忘れると plx⁻²。「plx 以上の星の総数（累積）」と混同すると plx⁻³。誤答がそのまま典型的なミスに対応している |
| 検証記録 | 専門家2/2（15分と45分）。2人目は「ネットで答えが見つかるかもしれない」とコメントしたが、非専門家は0/3だった。1人は85%の自信で plx⁻³ を選んだ。作問者の難易度の自己評価は「難しい学部レベル」 |
| 自分に解けるか | 解ける。確率密度の変数変換そのものなので、統計物理をやっていれば数分 |
| LLMの難所 | 計算は易しい。難所は「単位幅あたり（微分）」と「それ以上の総数（累積）」の読み分けと、ヤコビアンを忘れないこと。途中で1ステップ間違えると、そのまま誤答に着地する。また、人間がネットで調べても解けないように作られてはいるが、LLM は関連知識（Lutz–Kelker バイアスなど）を学習で見ている可能性が高い |

#### 問2：化学（有機）オレフィンメタセシスの生成物の数

| 項目 | 内容 |
|---|---|
| 何を問うか | ラセミ体（鏡像異性体の等量混合物）の 3-メチルペンタ-1-エンに Grubbs 触媒を作用させたとき、エテン以外の生成物は何種類かを、2・4・6・8 から選ぶ |
| 正解の考え方 | Grubbs 触媒による自己メタセシスで、3,6-ジメチルオクタ-4-エンができる。二重結合の E/Z が2通りあり、2つの不斉中心の組み合わせは (R,R)、(S,S)、(R,S) になる。(R,S) と (S,R) は同じ分子（メソ体）なので、E で3種、Z で3種、合わせて**6** |
| 誤答の作り | メソ体を見落とすと 2×4 = 8。不斉中心を無視して E/Z だけ数えると 2 |
| 検証記録 | 専門家2/2（20分と45分）、非専門家0/3。1人目の専門家の提案で、修正前は5だった選択肢を偶数に変え、選択肢を全部偶数にそろえた（奇数が1つだけ混じっていると、偶奇から消去しやすくなるため） |
| 自分に解けるか | 厳しい。メタセシスは調べれば生成物を描ける。分かれ目はメソ体の判定で、立体化学の訓練がないと 8 を選びやすい |
| LLMの難所 | 化合物名（IUPAC名）のテキストだけで立体構造を追い、メソ体を見抜くこと。「何を別物と数えるか」（鏡像異性体は別々に数える、エテンは除く）を作問者に合わせることも必要 |

#### 問3：生物（分子生物学）パイエル板のB細胞で起きている過程

| 項目 | 内容 |
|---|---|
| 何を問うか | 蛍光タンパク質（GFP）で標識したロタウイルスの内殻タンパク質をマウスに経口投与する。腸のパイエル板で増殖している細胞を取り出し、抗体の重鎖可変領域の配列を調べると多様性が高かった。起きている過程を、VDJ再構成・体細胞超変異・クラススイッチ・補体活性化から選ぶ |
| 正解 | 体細胞超変異。抗原の刺激を受けたB細胞が、二次リンパ組織で増殖しながら可変領域に点変異を入れる過程 |
| 誤答の作り | VDJ再構成は骨髄でB細胞が成熟する段階で起きる。クラススイッチが変えるのは定常領域。補体は配列の多様性と関係しない |
| 検証記録 | 専門家2/2（7分と15分）。2人目は「免疫学を履修したが、区別するのに20分かかった」。非専門家0/3。1人は2時間調べたうえで85%の自信で不正解。別の1人は論文中に VDJ という語を見つけて、それを選んだ |
| 自分に解けるか | 難しい。高校生物の「抗体の多様性＝遺伝子の再編成」という知識だけだと VDJ再構成を選ぶ。「抗原刺激の後」「二次リンパ組織」「可変領域」の手がかりを組み合わせられれば解ける |
| LLMの難所 | 知識は教科書レベルなので、LLM には比較的易しい。難所は、問題文中のノイズ（胃酸で蛍光が消える、粘液に絡まる）を無視して、時期と場所の手がかりを統合すること |

### 作成者と検証手順

#### 作成者の人数と立場

- GPQA 全体では、Upwork で雇った業務委託のフリーランサー61人が作問と検証をした。条件は、その分野で博士号を取得済みか博士課程に在籍中で、英語に堪能なこと。
- Diamond の198問に関わったのは、公開データで数えると次のとおり。
  - 作問者 35人（物理15、化学13、生物8。1人は2分野）
  - 専門家検証者 41人
  - 非専門家検証者 54人
  - 重複を除くと 56人（同じ人が、自分の分野では作問者か専門家、他分野では非専門家を務める）
- 作問者の報酬は1問 $10 の基本報酬に加えて、専門家が正解するごとに +$20、非専門家が不正解するごとに +$15、条件を満たせばさらに +$30。「専門家には解けて、非専門家には解けない」問題を作るよう報酬で誘導している。

#### 手順（1問あたり作問者1人＋検証者5人）

1. **作問**：問題文、正解、誤答3つ、解説を作る。
2. **専門家検証1**：解答したあと、解説を見て「正解は議論の余地なく正しいか」を判断し（事後同意）、フィードバックを書く。
3. **修正**：作問者がフィードバックを受けて直す（断ることもできる）。
4. **専門家検証2**：修正版を解いてフィードバックを書く（これ以降は修正しない）。
5. **非専門家検証×3**：ネット可・LLM禁止で、最低15分かけて解く。
6. **選抜**：Diamond の条件を満たす問題だけを残す。

### 採点方法と演習の評価セットとの違い

GPQA Diamond は四択問題であり、モデルが選んだ選択肢をあらかじめ定められた正解と照合し、正答率で評価する。公式の評価コードでは、選択肢を抽出できなかった回答も不正解として扱う。

今回の演習の評価セットは、講師 1 人が作成した 10 件の問題を、人と LLM で採点するものだった。一方、GPQA Diamond は 198 問からなり、複数の専門家による作成・検証と専門外の回答者による確認を経ている。また、採点方法は、あらかじめ定められた正解との照合である。したがって、問題数や作成・検証に関わる人数だけでなく、採点の仕組みも異なる。
